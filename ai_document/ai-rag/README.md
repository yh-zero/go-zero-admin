# 知识库演示语料

本目录保留供知识库问答使用的演示语料和人工问题示例，不包含离线评测脚本、题集或质量基线。

## 导入资料

1. 启动完整平台开发栈并登录管理后台。
2. 进入“AI 功能 → 知识库”，新建两个知识库。
3. 分别导入 `kb1-a股投资知识/` 的 6 篇和 `kb2-运维发布SOP/` 的 5 篇资料。
4. 等待状态变为“可使用”，再使用“向这个知识库提问”验证来源引用。

单篇资料最多 65,536 UTF-8 字节。TXT 和 Markdown 可以直接导入，CSV 和 JSON 可通过粘贴正文导入。

人工问题示例见 [test-questions.md](test-questions.md)。
