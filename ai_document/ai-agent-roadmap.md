# AI Agent 功能规划

更新日期：2026-11-02。以下为候选功能与建议顺序，尚未启动本规划的开发，不代表已确定全部实施范围。本次只整理文档，不修改代码、配置或依赖。

## 候选功能

| 功能 | 首版范围 | 难度 | 建议顺序 |
|---|---|---|---|
| 模型状态与连通性检测 | 展示已配置模型、配置状态，一键测试可用性、响应耗时及失败原因；密钥沿用 env，不回显 | 低 | 第一批 |
| Agent 配置中心 | 管理名称、系统提示词、使用模型、允许调用的工具，便于适配不同业务 | 中 | 第一批 |
| 用量统计与额度 | 按用户统计 Token、调用次数，设置每日使用额度；复用已有 Token 记录，补齐计数与额度控制 | 中 | 第二批 |
| 文档知识库 | 首版支持 TXT、Markdown；按文档回答并附原文来源，按权限隔离文档 | 较高 | 后续 |
| CSV 导入助手 | 识别表头、建议字段映射、提示异常数据，预览确认后导入；校验和写入由业务代码执行 | 中 | 按需 |

## 推荐推进方式

先完成“模型状态检测 + Agent 配置中心”，方便开发者确认模型可用，并通过提示词和工具配置定制 Agent；随后补用量统计，再评估知识库与 CSV 导入。

后续讨论的二、三期建议归纳如下，均为待选范围：

| 阶段 | 建议功能 | 首批建议 |
|---|---|---|
| 二期：运行与业务接入 | 执行记录与额度、业务工具调试和权限、轻量知识库、提示词版本、结构化输出 | 执行记录与额度 → 工具调试和权限 → 轻量知识库 |
| 三期：批量与复用 | 批量 AI 处理、Agent 模板导入导出、定时任务、APP 认证域下调用 Agent、可管理的偏好记忆 | 批量处理 + 模板导入导出，再补定时任务 |

本规划不重复列入此前讨论的聊天助手、后台业务查询助手、工作流及任务审批页面。已有 AI HTTP 接口、手动工作流及步骤审批是实现基础；定时调度、完整执行追踪、APP 认证域接入和进程中断恢复均不能据此视为已完成。现有能力与接口以 [API 契约](api-contract.md) 及代码为准。本文期数表示产品建议顺序，与 [架构方案](refactor-plan.md) 的架构阶段编号分开理解。

## 面向未来的最后一组功能

### 判断依据

截至 2026-11-02，以下方向已有公开协议或官方工程实践支持；它们对本项目的优先级是设计判断，不是对行业未来的保证。

- **业务能力开始以可复用格式交付。** Agent Skills 定义指令与参考资料的组织方式，MCP 定义外部工具与上下文的连接方式。对本项目的启发是把业务方法、工具接入与模型配置分开维护，方便以后替换模型。[Skills 规范](https://agentskills.io/specification)、[MCP 规范](https://modelcontextprotocol.io/specification/2026-07-28)
- **AI 交互可以直接呈现表单和业务操作。** A2UI 已公开用声明式数据描述界面、由客户端可信组件渲染的方案。本项目可以先复用 Ant Design 实现有限的业务卡片，按需求再评估协议接入。[Google A2UI，2025-12-15](https://developers.googleblog.com/introducing-a2ui-an-open-project-for-agent-driven-interfaces/)
- **长任务需要业务状态、恢复机制和结果验证。** 官方长期 Agent 实践指出，仅压缩上下文不能解决持续执行的问题；模型评估实践则强调核对真实结果及多次试验。对本项目的启发是先保存可验证的执行状态，再增加自动执行范围。[长期任务实践，2025-11-26](https://www.anthropic.com/research/effective-harnesses-for-long-running-agents)、[Agent 评估实践，2026-01-09](https://www.anthropic.com/research/demystifying-evals-for-ai-agents)
- **图片和文档会成为业务输入。** 官方文档抽取实践已覆盖图文理解、字段提取及业务校验。本项目适合从一种材料转表单草稿开始。[Google 文档抽取实践，2025-03-03](https://cloud.google.com/blog/products/ai-machine-learning/use-gemini-2-0-to-speed-up-data-processing/)

### 新增功能与最小范围

优先级是相对于本组功能而言；具体依赖前两期的权限、执行记录和结构化输出。难度是相对估计，不作为工期承诺。

| 功能 | 相比前三期新增什么 | 首版范围 | 优先级 / 难度 |
|---|---|---|---|
| **业务技能包（Skills）** | 将业务方法作为可供多个 Agent 使用、运行时按需加载的能力；超出完整 Agent 配置的导入导出 | 人工绑定技能；支持说明、步骤、示例和只读参考资料；固定版本并记录本次使用版本 | 优先 / 中 |
| **受控 MCP 连接管理** | 接入外部工具服务，减少每个工具单独编写适配逻辑 | 接入一个可信远程服务；连接测试、工具发现、白名单、启停和 Agent 绑定 | 优先 / 中高 |
| **业务卡片与操作预演** | 让用户直接核对并修改 AI 生成的业务草稿；在已有步骤审批上明确到具体操作和参数 | 先做表单、结果表格、变更确认三种卡片；展示目标及变更前后值，用户确认后调用现有业务接口 | 优先 / 中 |
| **可恢复的长任务** | 在已有任务快照和审批基础上，补齐服务重启后的任务识别与受控续跑 | 保存已完成步骤、进度与执行租约；支持取消和超时；先恢复只读或明确幂等的步骤 | 后续 / 高 |
| **图文材料转业务草稿** | 为二期结构化输出增加图片、扫描材料输入及原文证据 | 只选一种材料和一种已验证的模型，例如图片表单；提取字段、关联原图位置或原文、人工修正后保存 | 按场景 / 中高 |
| **模型迁移评测与选择** | 将提示词版本比较扩展为模型更换前的效果验收，并记录实际生效的模型配置 | 选 20–50 个脱敏真实样本，对比两个模型的任务成功率、耗时与用量；关键样本重复运行，人工决定切换并保留回退配置 | 优先 / 中 |

### 每项必须守住的边界

- **技能包**：首版读取说明和资料，上传脚本不执行；包内工具声明只作为需求，实际权限由服务端校验。版本、来源和许可要可查看。先验证人工绑定的效果，再考虑自动选择技能。[官方格式与按需加载约定](https://agentskills.io/specification)
- **MCP**：管理员限定可连接的服务和网络目的地，凭据沿用服务端配置并按归属使用；工具描述及返回内容不具有授权效力。工具定义变化须重新核对白名单，不能因重新发现工具自动扩大权限。实现前核对双方协议版本及适配器，协议兼容不等于业务权限兼容。[MCP 信任与授权原则](https://modelcontextprotocol.io/specification/2026-07-28)
- **业务卡片**：AI 只返回经过校验的数据，前端映射到允许的 Ant Design 组件；业务动作使用服务端登记的标识。确认绑定目标、参数和数据版本，提交时重新鉴权，重复提交不能重复执行。数据变化后重新预览；预演不产生写入或外发。首版不执行模型生成的 HTML、JavaScript 或任意请求地址。
- **长任务**：租约和重试不能保证外部操作只执行一次；外部写入结果不明时转人工核对，不能直接重试。取消只阻止后续执行，不承诺撤销已完成的外部操作。先明确每个工具的幂等和恢复边界，再开放自动续跑。
- **图文草稿**：保留可核对的来源，识别缺失、模糊或冲突字段交给用户确认；模型自报的置信度不作为自动提交依据。限制文件类型、大小及页数，资料使用范围与现有文件权限一致，调用外部模型前按部署策略控制数据外发。
- **模型评测**：在隔离环境、测试身份及独立数据上执行，每次试验重置测试状态；外部写入与外发使用模拟工具或服务测试环境，禁止向生产工具重放历史任务。校验真实结果和越权拒绝行为，结合规则检查与人工复核；不只让另一个模型打分。用量缺失标记为未知；费用只能按注明日期的价格估算。小样本通过不代表所有场景通过，模型切换不能自动重放已产生业务效果的任务。

### 选择顺序与采用条件

先做一套贯穿功能的最小场景：**一个业务技能 → 一个受控工具 → 一张结果或确认卡片 → 固定样本验证**。优先使用现有只读业务接口；MCP 在确实需要外部工具时接入。这能验证新增机制是否提高任务完成率，而不只是增加配置页面。

长任务在批量、定时任务出现真实恢复需求时推进；多模态从一种材料试点。工具、知识来源和用户记忆都应保留归属、版本及有效期，撤销权限或删除来源后同步处理检索索引、摘要和缓存，不能继续作为可用上下文。

跨平台多 Agent 委派（A2A）按真实集成需求采用：先有一个独立远程 Agent，再考虑任务提交、状态查询和取消。暂缓原因是当前项目需求与维护成本；协议已有稳定版，不能把“暂不采用”解释为“不成熟”。[A2A 官方发布说明，2026-03-12](https://a2a-protocol.org/latest/blog/2026/03/12/a2a-protocol-ships-v10-production-ready-standard-for-agent-to-agent-communication/)

自动学习反馈可先形成待审核的技能或提示词修改建议，经评测与人工发布后生效；浏览器代操作、任意脚本执行、模型微调及公开 Agent 交易市场留待独立需求论证，不作为本轮基础功能。
