# 服务器部署入口

完整部署步骤统一维护在 [README：服务器部署](../README.md#服务器部署)，包括源码打包、环境配置、数据库迁移、前端发布、升级与停止；请以该文档为准。

在后端根目录执行。首次准备完整源码及 `docker/.env.deploy` 后，Linux 最短启动流程为：

```sh
docker compose --env-file docker/.env.deploy -f docker/deploy-compose.yml config --quiet
sh test/sh/db.sh init deploy
docker compose --env-file docker/.env.deploy -f docker/deploy-compose.yml up -d --build
docker compose --env-file docker/.env.deploy -f docker/deploy-compose.yml ps
```

`init deploy` 启动依赖、备份并执行未应用迁移，不启动 API/RPC。Windows 对应 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\test\sh\db.ps1 -Action Init -Environment Deploy`。升级前使用 `backup deploy`，更新源码后按 README 停写、执行 `migrate deploy`，再构建服务。

开发依赖使用根目录 `docker-compose.yml`；部署使用 `docker/deploy-compose.yml`，数据卷独立。打包必须包含 `pkg/`、数据库脚本、`test/sh/` 和完整 `data/api/generated/`；更新接口后先生成 Swagger，再构建 RPC。
