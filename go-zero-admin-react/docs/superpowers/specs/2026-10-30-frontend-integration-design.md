# 前端对接设计

> 历史设计（2026-10-30）：本文记录初始前端阶段。2026-10-31 用户已授权必要后端配合，后续范围与验收状态以根目录 AGENTS.md 和 `ai_document/backend-api-integration-issues.md` 为准；临时测试代码已按用户要求在验证后删除。

仅修改前端仓库，沿用现有 React/antd/TanStack Query/zustand/axios。用户已明确要求直接完善前端对接，后端优化另行确认。测试数据仅写独立本地库，不改变后端源码、契约、生成物或锁文件。

集中响应兼容优于逐页面判断：统一接受契约信封、当前裸成功对象、空写响应，并拒绝 HTTP200 业务错误；使用标准 Bearer，401 与退出清理身份和查询缓存。表单使用 antd Form，服务端数据使用 Query，写成功失效相关列表。

实现 user/dept/role/menu/dict/api/file/audit/profile 和真实统计首页。用户和角色编辑先取详情、完整提交并保留授权。菜单为组件白名单且支持嵌套树，防止循环与外跳。权限读取失败不开放写操作；菜单失败可从已接入页面导航继续只读访问，所有实际请求仍受后端授权。

当前只有 RPC 的 App/AI/租户不虚构 HTTP；文件无上传接口，个人资料不能静默重置已有性别，角色菜单树失败不能清空原授权。已知后端 SQL/配置缺陷如实显示并记录。

按现有锁文件安装依赖。Node 内置测试验证响应、树和验证码；通过 tsc/Vite 后进行真实接口与浏览器验收。保留用户要求的测试数据，清理本次验证进程与临时文件。
